# EnergyPoint

Kerala's Premier Lithium-ion Battery Experience Center

## Project Overview
This is a high-end, futuristic two-page website:
- **index.html** — Stunning animated landing page with interactive infographics, comparison tools, and a multi-layer "Experience Center" explorer.
- **form.html** — Premium lead capture form. Submissions prepare a rich message for WhatsApp and provide email options.

## Key Features (as requested)
- Heavy JavaScript + GSAP-powered animations for a true futuristic experience center feel.
- Interactive "Why Lithium-ion vs Traditional" infographic with live-animating metrics.
- Multi-layer interactive Experience Center where visitors can explore aesthetic battery layers and different use-case environments (Residential / Commercial / Industrial).
- Zero maintenance, 5-year warranty, long-life messaging front and center.
- Location + interactive map at the bottom.
- Dedicated form page that collects leads for promotion.
- WhatsApp automation (prefilled message) + email capture path.

## Tech Stack
- Pure HTML + Tailwind CSS (CDN for zero build step)
- GSAP + ScrollTrigger (CDN)
- Leaflet for the map (CDN, no API key)
- Vanilla JS for all interactions and animations
- Fully self-contained — open index.html directly in a browser

## How to Run Locally
1. Open the folder in your file explorer.
2. Double-click `index.html`.
3. For the form: Click any "Enquire" or "Book Experience" button.

## Customization Needed (important)
- Replace the WhatsApp number in `form.html` (search for `YOUR_WHATSAPP`).
- Update the physical address and map coordinates in both files.
- Add your real logo if you have one (currently text + simple mark).
- Update email handling if you want fully automatic server emails (currently uses convenient client-side methods + WhatsApp).
- Replace placeholder stats or copy with your exact claims.
